# 隐私与边界

- GitHub 仅包含通用源码、文档与合成测试。真实任务、对话摘要和运行记录位于独立 DATA 目录
- 不读取聊天历史、助手内部指令、内部笔记、浏览器、邮箱、环境变量全量、其他项目或用户主目录文件
- 系统指标不输出主机名、账户名、IP、绝对路径、进程列表或内核完整版本
- 不采集遥测，无 CDN、分析服务或外部字体。正常运行无主动外网请求
- HTTP 只监听 127.0.0.1；无 HTTP 写接口、命令执行、文件浏览或下载 API。静态文件使用固定白名单
- Host 校验减少 DNS rebinding，跨站 Fetch 拒绝、无 CORS、CSP 禁止外部资源和框架嵌入。UI 用 textContent 渲染记录防止注入
- 本地服务没有登录鉴权；同机进程仍可能读取它。勿在不可信多用户机器上存储敏感内容，不要通过反向代理、隧道或公开端口暴露
- cgroup 限额无法读取或没有有限值时显示未知；指标可能是共享宿主机视图，不推断订阅权益或实际允许使用的资源
- 日志不自动脱敏。写入前人工筛选；不要记录邮件、个人身份、令牌、私人文件路径、未公开业务数据或完整对话
- 不提交运行截图，除非确认截图只含可公开合成内容。发布前检查整个跟踪文件清单，不能仅依赖 .gitignore
- 同步代码不等于同步运行数据；无自动云端备份或聊天同步功能

Web 界面语言偏好仅保存在当前浏览器 localStorage；不向外部服务发送系统语言，不翻译或上传任务 / 对话内容。

原生界面仅将 language: auto / zh / en 写入 DATA/config/ui.json，文件按0600保存；该配置与数据库均在源码仓库之外。切换语言不修改任务、运行或对话记录。

真实会话 thread ID、环境 ID、观察时间、可分享链接和来源 event ID 仅在 DATA 数据库中保存，不进入源码、截图或演示数据。绑定与摘要接入不保存平台凭据，不接受原始内部聊天。没有经过官方创建 / 读取确认时保持未绑定；URL 校验只防不安全协议和域名，真实性由调用方依据实际返回结果确认。

用户 Skill 清单只保存显式确认属于用户安装/编写的简短用途说明、场景、官方管理入口和人工核验元数据，全部位于私有DATA；不自动发现账户技能，不读取或展示系统/内部Skill。无Skill原文、账户链接或实际条目预置在源码与合成测试中。CLI的范围确认与URL格式校验不等于远端真实性核验，录入者需先核对来源。保存内容已核验也不代表最新、实时加载或自动触发。

出口地区为显式可选查询：只有运行 `PYTHONPATH=src python3 -m dots_panel.exit_region --data-dir <DATA>` 才向固定 HTTPS ipwho.is 端点查询一次面板后台网络出口。不会查询浏览器或用户设备位置；不保存原始 IP，只缓存大致国家/地区/城市、来源和观察时间。普通启动、5秒刷新均不发起查询。失败保留旧结果，超过24小时标为旧观察，无缓存显示未核验。此显示不改变时区或任务调度。第三方查询会看到发起请求的网络出口地址，使用前须获授权。
