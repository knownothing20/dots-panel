# App 内通知与未读提示

原生与 Web 视图只观察已经读取的本地快照，不创建执行者，不派发任务，不访问 GitHub，不自动更新软件。

- 新的 run 登记让活动未读圆点短弹一次；run 出现已登记参与者后，右上角展示任务卡。文案为“已登记分派”，不据此声称执行者正在运行
- 同一个 run 的多位参与者合并为一个任务通知。多条通知以堆叠卡片和“另有 N 条 / 下一条”呈现
- 大约累计 5 秒无悬停、无键盘焦点后，任务卡向右上角收缩并完全隐藏，不保留胶囊或常驻重开入口。只有新的真实分派事件可再次显示；旧未读仍可从侧栏对应分类查看
- 关闭或 Escape 隐藏卡片，保留未读。查看进度进入对应任务；进入分类标签清除该类提示。任务生命周期从不因此改变
- 活动、Agent、定时任务统一使用无数字的未读圆点。Agent 实际登记状态变化、定时结果的运行/状态标识变化各自触发一次短弹。观察时间、检查时间、普通心跳或完全相同的 5 秒刷新不会重复播放
- 第一次成功读取只建立基线，不重播历史通知。通知队列最多保留 50 张卡，当前快照的完整标识集合受保护，已移出快照的历史标识最多保留 2000 项，未读集合有界；当前未读状态属于本次窗口/浏览器访问，重开会重建基线，不是跨设备通知同步
- About 的静态 NEW 只在人工登记的已发布稳定数值版本高于本地版本时出现；未知、未发布、不规范标签及预发布标签不会被猜成“有更新”。页面原有本地版本、发布记录和最近核验时间继续保留

通知头像直接复用 Agent 列表的固定原创头像绘制入口；不另画不一致的默认头像。

鼠标操作不强制聚焦“查看进度”，不显示持续键盘边框，也不会仅因鼠标留下按钮焦点而永久暂停。鼠标悬停仍会暂停。键盘 Tab 焦点保留清楚的焦点提示并暂停计时；离开卡片后恢复。键盘查看进度会交接至详情，键盘关闭会把焦点还给页面。

通知是应用内的非模态浮层，没有遮罩、声音、焦点抢占或系统全局置顶。Web 使用 polite 状态播报和键盘按钮；原生保持键盘访问。减少动效开启时直接切换静态状态；Web 同时服从系统的减少动态效果偏好。

本功能不解决平台派发或记录延迟。必须先获得真实执行结果并及时登记。不能把通知卡、头像或活动角标当作平台执行证明。

## 验证范围

纯模型覆盖首次基线、重复快照、分派延迟、参与者合并、分类已读、状态/结果去重、严格稳定版本比较。有无显示服务器均可运行。控制器测试覆盖鼠标/键盘输入区分、hover/focus 暂停、完全隐藏但不已读、新事件再次显示、统一圆点、共享头像、查看任务和定时器清理。

```sh
env -u DISPLAY PYTHONPATH=src python3 -m unittest discover -s tests -v
for test in tests/*.js; do node "$test" || exit; done
```

真实桌面视觉、尺寸变化和键盘手感仍应在隔离合成 DATA 中人工检查。禁止将演示事件写进真实任务库。
